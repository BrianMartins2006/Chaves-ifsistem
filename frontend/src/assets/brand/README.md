# Logo IFConect

Coloque aqui a arte original enviada pelo responsável, com um destes nomes:
`ifconect.png`, `ifconect.svg` ou `ifconect.webp` (somente um arquivo).

O componente Brand utiliza automaticamente a imagem no login e no menu,
preservando sua proporção, incluindo em telas pequenas. Enquanto o arquivo não
estiver disponível, exibe o nome IFConect em texto, sem recriar a marca.

Execute `npm --prefix frontend run build` após adicionar ou substituir a logo.
